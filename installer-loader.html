OCTIME – Favori « Postes / jour »

Ce favori va chercher le code en ligne à chaque clic : il s'installe une seule fois et se met à jour tout seul quand le fichier hébergé change.

Sur ordinateur — glisse ce bouton dans la barre des favoris

Postes / jour

Affiche la barre des favoris avec Ctrl+Maj+B si besoin, puis va sur ton planning OCTIME et clique le favori.

Sur téléphone — copie le code et colle-le comme adresse d'un favori

  1. Crée un favori (par ex. ajoute la page actuelle aux favoris).
  2. Modifie-le : nomme-le Postes/jour et remplace son adresse par le code copié.
  3. Sur OCTIME, tape Postes/jour dans la barre d'adresse et choisis le favori.
Changer l'adresse du fichier hébergé (avancé)

Le favori est régénéré automatiquement quand tu modifies ce champ.

Bon à savoir

  • Un anti-cache (?v=horodatage) est ajouté pour recevoir les mises à jour immédiatement.
  • Fonctionne sur Chrome, Edge, Firefox, Safari (ordi et mobile).
  • Si rien ne s'affiche sur OCTIME et que la console (F12) montre une erreur Content-Security-Policy, c'est qu'OCTIME bloque les scripts externes : utilise alors le bookmarklet « tout-en-un » ou l'extension.
