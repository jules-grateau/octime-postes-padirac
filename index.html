Sur téléphone — copie ce code et colle-le dans l'adresse d'un favori :

Comment créer un favori sur téléphone ?
  1. Ouvre cette page dans ton navigateur et ajoute-la aux favoris.
  2. Ouvre tes favoris, appuie longtemps sur le favori que tu viens de créer, puis Modifier.
  3. Remplace l'adresse par le code copié ci-dessus. Sauvegarde.
  4. Pour l'utiliser : sur OCTIME, tape Postes dans la barre d'adresse et choisis ce favori.

2 Utilise-le chaque fois

  • Va sur OCTIME : ouvrir OCTIME et connecte-toi.
  • Dans le menu, ouvre le Planning de service (vue mensuelle).
  • Clique sur le favori Postes / jour dans ta barre de favoris.
  • Un panneau s'ouvre avec deux onglets :
    • Par poste — pour un jour donné, voir tous les collègues regroupés par poste.
    • Résumé — pour un employé, voir tous ses postes du mois et ses jours travaillés.
